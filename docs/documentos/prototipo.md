# Documentação do Protótipo – MVP Gestão de Farmácia

## 1. Tela inicial – Menu principal

**Objetivo:** Permitir que o funcionário acesse as principais funcionalidades do sistema.

**Componentes visíveis:**
- Nome do sistema.
- Menu de navegação.
- Botão de cadastro de medicamentos.
- Botão de consulta ao estoque.
- Área de alertas de validade.

**Ação principal:** Acessar o cadastro ou consultar o estoque.

**Navegação:** Entrada pelo acesso ao sistema e saída para as demais telas.

**Acessibilidade:** Botões com identificação clara, textos legíveis e navegação simples.

## 2. Tela de cadastro e controle de medicamentos

**Objetivo:** Permitir o cadastro e a atualização das informações dos medicamentos.

**Componentes visíveis:**
- Campo nome do medicamento.
- Campo quantidade.
- Campo preço.
- Campo data de validade.
- Botão salvar.
- Botão cancelar.

**Ação principal:** Cadastrar ou atualizar um medicamento.

**Navegação:** Acesso pelo menu principal e retorno após salvar ou cancelar.

**Acessibilidade:** Campos com rótulos identificados, instruções claras e botões de fácil compreensão.

## 3. Tela de alertas e resultados

**Objetivo:** Apresentar medicamentos próximos do vencimento e produtos com estoque baixo.

**Componentes visíveis:**
- Lista de medicamentos.
- Nome dos produtos.
- Quantidade disponível.
- Data de validade.
- Indicadores de atenção.
- Alertas de reposição.

**Ação principal:** Identificar medicamentos que precisam de atenção ou reposição.

**Navegação:** Acesso pelo menu principal e retorno para consulta ou cadastro.

**Acessibilidade:** Alertas com textos explicativos, identificação visual e informações organizadas.
